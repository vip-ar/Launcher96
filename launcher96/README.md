# واجهة 96 ميني (Launcher96)

واجهة خفيفة لتي في بوكس أندرويد: شاشة قفل بأوقات الصلاة والتاريخ الهجري وعدّاد رمضان، وشاشة رئيسية بتطبيقاتك.

## 1. البناء (على الكمبيوتر)
1. ثبّت Android Studio (آخر إصدار) إذا مش عندك.
2. افتح المجلد `launcher96` (File > Open) وانتظر انتهاء Sync (أول مرة بينزّل ملفات).
3. إذا طلع اقتراح تحديث Gradle أو Android Gradle Plugin، اقبله.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. الملف بيطلع هون: `app/build/outputs/apk/debug/app-debug.apk`

## 2. الخلفيات
- حط صورك الأصلية بمجلد، وشغّل: `pip install pillow` ثم `python tools/prepare_wallpapers.py مسار_المجلد`
- السكربت بيحوّلها 1920x1080 WebP وبيحطها بمكانها، وبتتبدل كل 10 دقائق.
- لو ما حطيت صور، الخلفية بتكون لون غامق عادي.

## 3. التثبيت على الجهاز
1. فعّل خيارات المطوّر و USB debugging (أو ADB عبر الشبكة) على التي في بوكس.
2. من الكمبيوتر: `adb connect عنوان_الجهاز:5555` ثم `adb install -r app-debug.apk`
3. اضغط زر Home، واختر "واجهة 96" وخليها دائماً.

## 4. تعطيل الواجهة القديمة (بعد ما تتأكد إن الجديدة شغالة)
- تعطيل: `adb shell pm disable-user --user 0 com.google.android.tvlauncher`
- رجوع: `adb shell pm enable com.google.android.tvlauncher`

## ملاحظات
- أوقات الصلاة تقريبية (حساب فلكي لعمّان)، ممكن نعدلها لجدول وزارة الأوقاف.
- الطقس بيتحدث من الإنترنت كل 30 دقيقة.
- الاختصارات: أي زر من القفل يفتح الرئيسية، Back من الرئيسية يرجع للقفل، وبعد 3 دقائق بدون لمس بيرجع للقفل.
